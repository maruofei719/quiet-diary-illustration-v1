# Quiet Diary Illustration

> Turn photographs into images that feel remembered during a dream.

Quiet Diary Illustration is a photo-to-poster system for creating quiet, dreamlike experimental editorial images. It removes the original photographic space, preserves one recognisable memory anchor, and lets source-derived motifs echo, mutate, overlap, drift, or disappear through analog print materials.

The result is neither a filtered photograph nor a rigid collage. It is a new composition held together by associative memory.

## Use in Codex

Install this repository as a skill, attach one or more photographs, then invoke:

```text
Use $quiet-diary-illustration-v1 in Associative Memory Mode. Keep one recognisable memory anchor, remove the original photographic space, choose one associative grammar, make one source motif echo or transform, dissolve at least one boundary, create one precise impossible relationship, generate the poster, inspect it against the quality gate, and return the image, grammar, and exact prompt.
```

## Core principles

1. Preserve one emotional memory anchor, not the photographed scene.
2. Organise through echo, metamorphosis, disappearance, or impossible continuity.
3. Let materials overlap, erode, ghost, and contaminate one another at the edges.
4. Use negative space as an active trace, not an empty leftover.
5. Reject any result that reads as a full photo, a filter, or countable modular collage.

Four associative grammars make the system repeatable without imposing fixed arrangements: Echo and Drift, Metamorphic Bridge, Vanishing Memory, and Impossible Continuity.

## Status

Version 5.0 replaces fixed piece counts, percentage quotas, and rigid composition recipes with stable dream-logic rules. Each poster must retain one clear anchor while including a source-derived transformation, a dissolved boundary, and an impossible spatial connection.
